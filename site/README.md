# Feynman Path Integral Engine — showcase site

Static site for the Euclidean path-integral computing project.

## Run locally

From this directory:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Open <http://127.0.0.1:8765/>.

## Contents

- Live atmosphere (imaginary-time lattice / worldlines)
- Interactive Brownian-bridge sampler and density estimate (browser port of `cpp/feynman/direct.hpp`)
- N–T exact lattice map from suite `exact_alpha.csv`
- Milestone results and suite figures
- Formative poster (PDF + PNG)
- GitHub: https://github.com/Zam1r/Feynman_Path_Integral_Engine

Design review cycles: documented in the project store at `docs/site-review-cycles.md`.
